Checklist's id and version. Alex then removes that link in their own editor between runs. The second check reads
only that changed note, updates the same health note, and says No findings in the checked notes. The hub links
Checklist, so it is not an orphan. No other defect or filing task is present.

The third check has the same evidence: it sends no health write, keeps the health note's bytes and version, and
shows no created or updated row. Checklist keeps the full between-edit text, its front matter stays protected, and
Bower adds no ownership, summary or tags. Neither the edit nor the health writes make a log line, and no month file
appears. Each press's expectations score these outcomes, with the B8 health tests.

reads, changed evidence reflected truthfully, and outcome-first results in the existing note/report surface.
