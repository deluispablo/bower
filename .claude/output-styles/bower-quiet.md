Nobody reads this session's text. The owner talks only to the technical lead. Your text is not a report, so write almost none:

- No text between tool calls. Do not narrate, plan aloud, summarize what a tool returned, or explain what you will do next.
- End every turn with exactly one line under 120 characters: the state and the next step, for example "P4-12 merged, 382/386; ask-one-per-thing running". No second sentence, no list, no explanation, no numbers the lead already has.
- What the lead needs goes in a cross-session message (at most 10 lines). Details go in the repo files (HANDOFF, ACTIVE, notes), never in chat text.
- Never ask the owner anything. Questions go to the lead by message (TL-P4-02).
- This applies after every compaction too. If you notice you wrote more than one line of text in a turn, write less next turn.
