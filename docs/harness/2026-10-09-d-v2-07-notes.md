- `a tap during carry or write cuts the pose cycle and the loop resumes`: tail 0 after the tap (carry pins it), expected > 3.

What changed (mechanism homes kept: `useBirdEngine`'s look source, the engine's one tap slot, `interrupt({ now: true })`):

1. A keydown with focus on body calls `look(null, 'focus')`: it marks recency and wakes a dozing bird (the wake's startle),

2. `look` takes a point or a getter. A focused control's place is read each frame, so scroll and layout changes move the
   gaze; the getter gives null once `document.activeElement` is no longer the control (blur, focus to body, removal),
   and the focus gaze ends. No focusout or scroll listener is needed beside it.
3. The tap slot is checked at every action end (`think()`), and before the carrying return at home.
   It plays `hello()` without cutting the rest of the script, so a scene's flights and `settled()` stay as written.
4. `perch()`'s carry and write branches stop writing their targets once `poseActed` is set by the tap; the next cycle
   resumes the loop. `B.carrying` is kept.
5. `heard()` cuts a running snap or preen through `interrupt({ now: true })`; the gaze then follows.

## Round 3

Red 1371da20, fix 5c2529ea. Each red failed on an assertion before the fix:

- `input during a preen between flights keeps the queued flight and its callback`: callback called 0 times, expected 1.
- `the iris returns from a lost focus gaze in a working pose`: write pose, iris y off rest by 0.75 0.5 s after blur,
  expected < 0.2.
- `a body keydown keeps a live pointer gaze`: iris x 0.4 (rest) 0.3 s after the key, expected < 0.

What changed (mechanism homes kept: `interrupt({ now: true })`, the engine's gaze channel, `useBirdEngine`'s look source):

1. `interrupt({ now: true })` cuts only the action and act under way; it no longer clears `S.queue` or the tap slot.
   Plain `interrupt()` still drops both (setPose, BowerController). So `heard()` cutting a snap or preen keeps a layer
   script queued before the next frame, and a tap on a layer bird with a script goes to the slot and plays after the
   current action (addendum 3 (4)).
2. `gaze()` with no live input, in a working pose (`head` null), puts the iris targets back at `IRIS_REST` (0.4, 0),
   the springs' rest and idle's `rest()` value, now one constant. Idle, wait and layer birds keep `rest()` plus acts.
3. `look(null, ...)` marks recency and wakes a dozing bird, and leaves `S.ptr` as it is, so a body keydown keeps a live
   pointer gaze. A lost focus gaze still ends through its getter returning null.
