# Packet: r2-oidc-two-accounts (P3-B, owner session)

Starting model: `bower-evaluator` (Sonnet). Reason: a guided probe on staging in the built-in browser pane, with the owner at the Google pages ([TL-P3-09](DECISIONS.md); procedure from the lead, 2026-10-07).

- **Target:** the staging origin in `docs/harness/STAGING.md` (deployed after P3-5), opened with `?source=real`. Use the **built-in browser pane** only (`mcp__Claude_Browser__*`), on a fresh origin state (clear site data for the staging origin first), and record the served bundle name and the Worker `/health` version before any reading.
- **Accounts:** only "test account A" and "test account B". Never write an address, a name shown by Google, a folder id or a token into the report, a screenshot name, a log line or a message: redact them as `A`, `B`, `FOLDER_A`, `FOLDER_B`.
- **The Google pages are the owner's.** When the pane reaches `accounts.google.com`, stop. Report exactly one line to the coordinator: "Waiting for the owner to sign in as test account A" (or B). Do not type, click or read form values on Google's pages. Continue only when the app's page is back.
- **Steps (in order):**
  1. A signs in. `/me` shows a user; `POST /vault` (through the app's folder step) answers `found: false` the first time and creates a Bower folder: the app shows the five main folders. Record `FOLDER_A` only as a fingerprint (the last 4 characters).
  2. A signs out. `/me` answers 401.
  3. B signs in. `/me` shows a different user. B's folder step creates `FOLDER_B` (different fingerprint). B's file list shows nothing of A's.
  4. With B signed in, call `GET /drive/token` and use it (by script, read-only `files.get` with `fields=id`) on `FOLDER_A`'s id: expect 404 or 403 from Drive. Then call `POST /vault` again: `found: true`, same `FOLDER_B`.
  5. B signs out; A signs in again: `found: true`, same `FOLDER_A`; nothing of B's visible. Reverse the step-4 check (A's token on `FOLDER_B`).
  6. Copy A's session cookie value into a new incognito-like context (clear cookies, set it by script on the staging origin) after A signs out: `/me` answers 401 (logout retired it).
- **Never** delete, rename, move or write anything in Drive beyond what the app's folder step creates.
- **Pass:** every step as expected. Anything else: step, expected vs actual (redacted), screenshot path under `/private/tmp/p3-r2/`.
- **Return under 20 lines:** bundle and Worker version, a table of steps with pass/FAIL/NOT RUN, findings, and the owner prompts you sent.
