## Proposed compatible contract — recommendations, not a ruling

**One home:** extend timeline-line.ts with a small marker-text formatter and its field
validation, imported by note-edit and producers. Keep parseTimelineLine/timelineLine as the
only Timeline reader/writer. Keep persisted `EditEntry {date,text,source}` and display
`TimelineEntry` unchanged. Marker intent is resolved to ordinary text **before** the
manifest is authored; readers do not reconstruct an action or authority from that text.

Proposed execution line additions: optional `marker: 'contradiction' | 'uncertain' |
'inferred'`, optional `alsoCites: [<exact existing source path>]` (at most one). The
existing `cites` remains the admitted thing/pile selector. `alsoCites` is only legal with
a marker and is a non-mutating reference, never a target grant or an instruction to read
outside the selected neighbourhood. Resolve it through VaultIndex against source links
already present in a shown selected note (or another admitted source), retaining the
resolved file id/version in the existing planning evidence. Do not accept merely an
existing file name as evidence; duplicate names require an unambiguous displayed path.
No extra raw source download is necessary just to reuse its already shown citation.

The model supplies unlinked claim text. Script binds sources, validates, then formats:

- Contradiction: `Contradiction: <text> (also from [[<older source>]])`.
- Source uncertainty: `Uncertain: <text>`; an extra source suffix is optional.
- Inference: `<text> (inferred)`; an extra source suffix follows the qualifier.
- The existing terminal ` · [[<new source>]]` follows all of those in timelineLine.

No `> ` prefix inside a Timeline entry: it would be literal, not a quote, in that display.
For an already writable prose region, the **same marker-text formatter** may be used
with its prose quote option to produce `> Contradiction: …`; it does not create or grant
a region. A region rendered by Inline keeps that leading character literal. No new
prose-write operation is proposed; B4/B5/B6 own those producers. Source-note bodies are
never rewritten to decorate their extracted/copied text.

Strict write permits only script-produced canonical source suffix tokens (no alias,
heading/block target, nested bracket, newline or grammar delimiter), with existing link
identity/name rules. After formatting, the final text including labels and extra link
must fit **AUTHORED_LINE_MAX = 200**. Existing source-name validity and date checks remain.
An overlong result refuses/retries, never clips away a claim or condition; do not raise
this red's limit. Read mode keeps historically admitted entries readable and literal,
including old callout-looking text, unknown tags and formerly uncited news. Invalid
ownership still uses the existing typed refusal; tolerant marker text must not relax
ownership boundaries. Marker labels have one stable English home, future-language
mapping handled by the existing language design rather than another producer constant.

Plain-note example for case 1 (proposed exact new bytes, not a second grammar):

```markdown
## Timeline
- 2026-10-02 · The earlier listing gives rent from 2026-11-01 as 1,450 a month. · [[Earlier listing.txt]]
- 2026-10-07 · Contradiction: Earlier terms give 1,450; later terms give 1,580 for the same period. Neither is confirmed. (also from [[Earlier listing.txt]]) · [[Later listing.txt]]
```

The app shows a dated entry beginning “Contradiction:”, the older link inside the text,
and its existing “From” source for the new file. A plain editor sees both links in the
single bullet. No marker status is stored: a later sourced resolution is another C07
line, never deletion of the historic disagreement. A derived B-region rebuilt by its
existing owner retains evidence qualifications through its own contract; B9 does not
make archives, hot or an `(inferred)` string trusted context.
