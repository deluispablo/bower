## What changed and API

Pure internal `parseOwnership(bytes: Uint8Array): OwnershipResult` validates fatal UTF-8 without replacement decoding; preserves the initial BOM as structural prefix only for exact v2 opt-in; returns plain/legacy/v2 or invalid with unsupported-version/damaged-boundary/invalid-encoding. Invalid results have no personal/payload/task authority. V2 validates exact closed frontmatter declaration, four ordered marker pairs, no duplicate/nested/unknown boundaries or unclaimed content, exact source-byte payload offsets, fence/escape behavior and no lone CR. Existing TASK_LINE is reused; no Markdown/YAML dependency or I/O is introduced.

Valid v2 exposes four half-open payload byte spans and personal actionable tasks with actual checkbox byte positions. Framing/task scans share the same fence transition:0–3 spaces, backticks/tildes≥3, same-character adequate closing run with only spaces/tabs, no backtick in backtick info. Fenced examples and empty labels do not consume v2 task indices; escaped markers remain literal source content. Ordinary headings never establish v2 ownership.

Legacy/no-frontmatter retain their existing structural/body and task-index meaning, including disputed legacy task0 and selected personal task1; plain marker-looking text remains personal. Legacy fence/empty-task indexing and initial legacy BOM behavior are explicitly retained. Canonical legacy reported personal span excludes leading blank separators as independently specified in the manifest, without changing actionable task ownership. No existing legacy parser/renderer is replaced.

Pure internal `togglePersonalTask(bytes, { index, label, previousDone, done }): TaskResult` reparses the supplied actual source each time, checks integer index plus selected label/prior checkbox state, and changes only the selected ASCII checkbox interior byte in an independent Uint8Array copy. It accepts no cached span/mutation authority argument. Refused outcomes expose typed ownership/task-not-found/task-changed reasons; original input remains unchanged even for slice-sharing Uint8Array subclasses such as Node Buffer. This is an internal typed API proposal consistent with the adopted pure grammar, not a public Sources/Drive/Worker wire change.
