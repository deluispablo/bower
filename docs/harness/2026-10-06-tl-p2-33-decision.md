# Technical-lead decision TL-P2-2026-10-06-33: runner files, the missing journal and counting rules

Lead: Claude `Planificador`. This answers the questions from lane b-runner-files (`b-path-unreadable-runner-files` and `o5-rules-wording`).

1. **Register `b-path-missing-journal` with the proposed rule.**
   - **Missing folders.** When `.bower/changes` or its archive folder is missing, the run plans as if the journal were empty. It takes no legacy path.
   - **Creating them.** A missing folder is created by the first operation that needs it, with a keyed `create-folder`, and never otherwise.
   - **A failed read** refuses the run before admission with "Bower couldn't read its own files. Try again." (TL-P2-17).
2. **Implementer decisions: ratified.**
   - **(a)** A missing `requests.json` or `hashes.json` is created with `create-text` (`purpose: 'runner-json'`) at its supported path under the verified `.bower/` parent. B's runner-json purpose covers creating one of those three supported files. Refusing would block every later run.
   - **(b)** A missing `Rules.md` follows B.2 as ratified (M6 and R3-4):
     - it is made with `create-text`, with `purpose: 'generated'`, `by: bower`, `bowerNew: 1` and `bowerItem` = `createKey`;
     - each rule's archive `dependsOn` that create;
     - `rulesWorded` is the number of rules `parseRules` reads from the created text.
   - **(c)** A `Rules.md` that is not Bower's, is damaged or is too big leaves its rule records pending and uncaptured, and logs one `BowerError` (B.2 rule 7).
   - **(d)** A file whose digest cannot be checked is left out of `hashes.json` for that run. At worst, one exact duplicate goes unnoticed until the next run (TL-P2-18). No legacy path.
3. **Counting: 0, not 1.** Contract B grounds `yourChanges` as the number of archived records that are not requests or rules (TL-P2-23). Rule removals and duplicate added rules are rule records, so they count 0 on B. New rules show in `rulesWorded`. A removal is visible in `Rules.md` itself. Legacy's count of 1 is a legacy difference, and it is not carried over.

No external standard applies; all of this is internal to contract B.
