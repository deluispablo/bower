## Contract (ports only)

1. **Prefix read (Q3).** A port that reads a note's first 4,096 bytes with `alt=media` and `Range: bytes=0-4095`. A 206 gives the prefix; a 200 with the whole file is cut at 4,096 bytes; 416 and an empty body are handled; a cut inside a UTF-8 character drops back to the last whole character; Google Docs and other exports are not read (not notes). The prefix never enters the full-media read cache as if it were the whole file.
2. **Changes feed (Q10).** Ports for `changes.getStartPageToken` and `changes.list` that drain every page to `newStartPageToken` and return the changes (including removed stubs and unrelated account changes) and the new token; a `parents` lookup that walks an unknown id up to the Bower folder to decide scope; more than 50 unknown ids reports that a bounded full listing is needed (the caller decides). My Drive only.
3. **Fake parity.** The fake Drive implements the same ports with the same shapes, covering 206, 200-full, 416, empty, multi-page feeds, removed stubs and out-of-scope ids; the parity test runs both.
4. **Out of scope:** no retrieval.json, no cursor commit, no index building (B1a, B1c). No new app UI. Existing Drive-call goldens do not rise for existing paths.
5. Errors are BowerError with one short sentence; details to console.error. Compatibility rows for any src/data/contracts commit (none expected).
