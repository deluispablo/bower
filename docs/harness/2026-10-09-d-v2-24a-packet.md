## Contract

1. **One port.** Add `react(kind)` in `src/bird/`, for example `bird/react.ts`, exported for screens.
   - Through presence (`activeHandle()`), it routes one reaction to the bird that has the turn.
   - Screens pass a kind; the port maps each kind to engine actions.
   - Screens never drive parts.
   - There is no controller per screen and no `useRef<BowerController>`.
2. **Kinds, from bower-map.md's "Reacts when you…" column.** This entry adds the engine actions; 24b wires the screens.
   - `point-tidy` (tuft up, lean in)
   - `yes` (two nods)
   - `no` (head tilt)
   - `drag-over` (lean forward, beak open)
   - `duplicate` (head tilt at the line)
   - `task-done` (short chirp)
   - `link-open` (follows with its eye)
   - `drop-folder` (small hop)
   - `bin` (startle, then a look at Undo)
   - `send` (two nods and a chirp)
   - `rule` (carries a small paper)
   - `moves-off` (settle: once, 0.6 s, eyes closing, body easing to the perched still frame, then hold)
   - `moves-on` (wake and shake the feathers, 0.4 s)
   - `hide` (one wing wave)
   - `done` (show off, tail fan)
   - `error` (startle, alarm pose, then a look at "Try again")
   - `online` (small hop)
   - The flights for Add's catch, the save carry and Home's fly-back reuse the existing layer actions (`flyTo`, carry). This entry exposes them as kinds only where the map names them. List the full kind-to-action table in the notes, one row per kind, citing the map row.
3. **Timing (spec rules, via d-v2-07's mechanisms).**
   - There is one reaction at a time, and a new one interrupts the old.
   - A reaction starts within 0.1 s: it cuts the idle act or the reaction under way at the next frame (`interrupt({ now: true })`), and springs from the current pose.
   - A flight or a carry is never cut. A reaction that arrives during one keeps only the latest one, in the same one slot as the latest tap, and plays it on landing. Do not add a second queue.
4. **New engine actions.** Add `nod`, `tilt`, `lean`, `startle` (the existing `nudge` startle, reused), `settle`, `shake` and `wave`. They are named acts through `act(name)` or the existing actions, with values in the act table style: angles and seconds in the notes, and the reference fixture extended for them.
5. **Still when asked.**
   - With reduced motion, the port does nothing, including no settle. The still frame shows at once.
   - With "Bower moves" off, the port does nothing, except `moves-off`'s own settle and `moves-on`'s wake and shake.
   - A bird in the sleep pose ignores reactions, per addendum 1 (4); the designer may rule otherwise for `error`.
6. **No new copy, no speech bubble, no tip.** Bower never covers content and never blocks input.

**Reference rows (TL-P4-22 addendum 20).** `pose-reference.fixture.ts` gains one row per kind (17), with the designer's values. The meta-test from the d-v2-07 startle round (`every engine act has a reference row`) enforces it. This entry starts after the startle round merges.
