# Bower v4 board walk (29 September 2026)

**For the technical lead.** Every non-deck board in `docs/design/v4/boards/` walked against the demo build (`pnpm -C app build:demo`, served by `vite preview` on port 4271), on a phone (375 x 812) and a desktop (1440 x 900) viewport, in Chromium driven by a Playwright script (the Playwright MCP could not start its Chrome, so the repo's own `@playwright/test` and its bundled Chromium were used; page text was read from the DOM and compared with the boards' text, and side-by-side screenshots were used where text was not enough). Build under test: `origin/main` at `bf7d0f7` (#681). The demo's scripted tidy-up (Add a file and a link, Tidy up, Yes) was run to reach the "after a tidy-up" state; because the demo state is in memory and resets on every full load, in-app navigation was used after the tidy-up. Both themes were checked on the Notes tab. Ignored, as agreed: differences that only come from sample content (dates, counts) and the boards' fake status bar. No personal data appears here; sample names are the demo's.

Count: the task says 51 non-deck boards; the folder holds **50** (65 files minus 14 decks minus `canvas.json`). All 50 were walked: **22 match, 28 mismatch**. Findings: 7 major (issues #683 to #689) and one grouped minor issue (#690).

## 4. What matches and works

- The five folder colours in dark and light, kind badges grey, Bower's note card and its source marks, the key-facts strip in one to four cells and in list rows.
- Notes tab: Just filed row, tree with New counts, Reveal, Mark all seen, light theme.
- Folder: chips, By Bower with the explaining line, Compare, empty state, quick look, list and grid toggles.
- Add: Photo, Files, Drive doors (camera shown with a fake device), link with LINK badge in the queue, "Tidy up n things", confirmation, working sheet, Done with "See where everything went".
- Search: start state with recents, filed-in-last-tidy-up and Searched before; typo forgiveness; "Nothing called …".
- Desktop: three panes with keys line, About panel, Just filed table, Ctrl K two-column search.
- Move picker: search, "Where it is now", both actions; the request is written.
- Filtering: system files never appear.

## 5. Left out

Deck-* boards (as instructed); zoom readout on the full-screen photo; Add-time "kept, not read" messages for HEIC, audio and Office files; signed-in behaviour of Drive previews (the demo has no Drive); the first-load Notes skeleton (not reproducible in the demo); 375 px only on phone and 1440 px only on desktop (no 768 or 1024 pass).
