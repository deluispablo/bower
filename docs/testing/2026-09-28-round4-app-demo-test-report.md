# Bower app and demo test report (28 September 2026, round 4)

**For the technical lead.** Exploratory session over the deployed real instance (the operator's domain, signed in as the test account in the built-in browser) and the public demo (`bower-demo.pages.dev`), at 375, 768, 1024, 1280 and 1920 px, with the four personas (experienced, technical, new, chaos), a read-only pass and a real-actions pass (authorised by the owner: two real runs, one rule, one question, one pin/unpin, a theme change, a Picker pick, sign out). Build under test: the repo's `origin/main` is at `073306f` (#476); the site is on the wave-6 build (`f66db3e`, inferred: the fixes for #426, #464, #465, #446 and the M24 container are on main and not on the site), so section 2.3 lists what is merged but not deployed and every "not deployed" row in the log is a redeploy, not new work. M25 (demo, #361–#367) and M26 (agent) are in flight: the demo's v3 screens and the file-only ingest are not expected yet and are not reported as broken (they are listed once, in 2.2, for the tick). Previous report: `docs/superpowers/plans/2026-09-28-app-test-findings.md` Part A (round 1) and the tester rounds 2–3 filed as #420–#427, #443–#447, #464–#465. Decisions taken without asking: the demo was tested first; the owner signed in to Google in the pane (the tester never types passwords); a Google Sheet was the Picker file the owner chose; the session ended signed out, as authorised, so the owner has to sign in again. Evidence: the built-in browser cannot save screenshots to disk, so every finding cites the session log row and the DOM or console text read at the time; the screenshot names in earlier rows are what was looked at, not files. No personal data is quoted: the test account's notes are referred to as "a note", the account as "the test account".
Severity: P0 breaks the product promise or blocks a flow; P1 a person notices every day; P2 polish. Reproducibility noted per bug.

- New user, real: pinned a note while a run was in progress → fine; the Last tidy-up card blanked during the run (1.9).

- IDEA: the version line with the commit (3.9); a "Starting…" state right after Yes (3.1); keep the demo's `tourSeenAt` in localStorage with the intro flag (1.4).
- RISK: a copy handler fired on a nav click in the demo (4.5); the lint's Urgent finding about a file in the test inbox (4.6); the runner still on the v5 workflow so rules kept at once are not followed yet (the "Learning" rule was ignored by the run: M26).
