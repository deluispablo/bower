# Bower v4, the explorer and what Bower reads

The design the v4 milestones implement, 28 September 2026: finding, seeing and understanding what is in the Bower folder, on the phone first and on the desktop. The decisions, the review and the plan are in [`docs/superpowers/plans/2026-09-28-explorer-ideas.md`](../../superpowers/plans/2026-09-28-explorer-ideas.md) (ideas, benchmark, owner decisions) and [`docs/superpowers/plans/2026-09-28-explorer-v4-spec.md`](../../superpowers/plans/2026-09-28-explorer-v4-spec.md) (the implementation spec). Where a board and the text disagree, the board wins.

Open any `boards/*.dc.html` in a browser; `boards/canvas.json` holds the layout and each board's title. Phone boards are 390 × 844, desktop boards 1440 × 900, deck slides 1920 × 1080. Sample content is "Alex", a fictional person.

## How they were made

Generated by a Python script over the v3 boards' stylesheet and bird (the script lives with the design session; the boards are the source of truth). The working copy is the Design canvas; this folder is the record.
