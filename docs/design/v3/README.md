# Bower v3, the screens

The design the v3 milestones implement, 28 September 2026: every screen of the app and the demo after the UX round with the owner. The decisions and the plan are in [`docs/superpowers/plans/2026-09-28-app-test-findings.md`](../../superpowers/plans/2026-09-28-app-test-findings.md) (Parts C to E). The boards here are the same files as the lead's private review canvas; where a board and the text disagree, the board wins.

Open any `boards/*.dc.html` in a browser. Each is a self-contained page at the board's size (phone 390 × 844, desktop 1440 × 900); the links between screens work from the file system (Play). `boards/canvas.json` holds the layout (rows, positions) and each board's title. Sample content is "Alex", a fictional person; nothing in these files comes from a real folder.

## How they were made

Generated by a Python script over the base generator of the previous set (`docs/design/gen.py`: the bird, the icons, the stylesheet, the page frame) with the soft palette and the v3 components on top; the script lives with the lead, the boards are the source of truth. To change a screen, edit its `.dc.html` (the markup is plain HTML with inline styles and one `<style>` block) and keep the root element at the board's size.
