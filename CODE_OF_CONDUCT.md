# Code of Conduct

Be kind, be direct, assume good intent. Disagree with ideas, not people. No harassment, no discrimination, no personal attacks, in issues, pull requests or anywhere this project is discussed.

Maintainers may edit, remove or reject contributions and comments that do not follow this, and may block repeat offenders. To report a problem, use GitHub's report feature or contact the maintainer through the repository's Security tab (private reporting), which reaches only them.

Adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
